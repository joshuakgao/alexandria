# Playing Atari with Deep Reinforcement Learning

![[2013-dqn-thumbnail.png]]

## Research gap

Prior reinforcement learning methods relied on hand-crafted features combined with linear value functions, limiting their applicability to high-dimensional sensory inputs. Attempts to combine deep neural networks with RL faced three fundamental challenges: (1) correlated sequential training data violates the i.i.d. assumption of deep learning, (2) the data distribution shifts as the policy changes, destabilizing training, and (3) non-linear function approximation with Q-learning was known to diverge. No method had successfully learned control policies directly from raw pixels using deep networks.

## Contributions

- Introduces **Deep Q-Network (DQN)**, the first deep learning model to successfully learn control policies directly from high-dimensional sensory input (raw pixels) using reinforcement learning.
- Proposes combining Q-learning with **experience replay** — storing transitions in a replay memory and sampling random minibatches — to break temporal correlations, stabilize the data distribution, and enable off-policy learning with deep networks.
- Demonstrates a single architecture and set of hyperparameters that learns to play seven Atari 2600 games, outperforming all prior RL methods on six and surpassing a human expert on three.
- Shows that despite lacking theoretical convergence guarantees, deep Q-learning with experience replay trains stably, with the predicted Q-value serving as a smooth progress metric.

## Method

DQN applies Q-learning with a convolutional neural network as the function approximator:

1. **Preprocessing**: Raw 210×160 RGB Atari frames are converted to grayscale, downsampled to 84×84, and the last 4 frames are stacked as input (providing velocity information).
2. **Architecture**: Two convolutional layers (16 filters 8×8 stride 4, then 32 filters 4×4 stride 2) followed by a 256-unit fully-connected layer and a linear output layer with one unit per action (4–18 actions). All hidden layers use ReLU activations. Outputs Q-values for all actions in a single forward pass.
3. **Experience replay**: Agent transitions (s, a, r, s') are stored in a replay memory of size 1M. Training minibatches (size 32) are sampled uniformly at random, breaking temporal correlations and stabilizing learning.
4. **Training**: ε-greedy exploration (ε annealed from 1.0 to 0.1 over 1M frames). RMSProp optimizer. Reward clipping to {-1, 0, +1} enables a single learning rate across games. Frame-skipping (k=4) lets the agent play ~4× more games without proportional compute increase.
5. **Loss**: Standard Q-learning TD error: L = (r + γ max_a' Q(s', a'; θ_{i-1}) - Q(s, a; θ_i))², with target network parameters θ_{i-1} held fixed during each optimization step.

## Datasets & evaluation

**Environment**: Seven Atari 2600 games via the Arcade Learning Environment (ALE) — Beam Rider, Breakout, Enduro, Pong, Q*bert, Seaquest, Space Invaders. 210×160 RGB at 60Hz. No game-specific information or hand-designed features provided.

**Baselines**: Sarsa with hand-engineered features, Contingency (Sarsa + learned controllability features), HyperNEAT (evolutionary, with hand-engineered object detectors), random policy, and human expert (median over ~2 hours of play).

**Key results:**
- DQN outperforms all prior RL methods on 6/7 games.
- Surpasses human expert on 3 games: Breakout (168 vs. 31), Enduro (470 vs. 368), Pong (20 vs. -3).
- Falls short of human performance on games requiring long-term strategy (Q*bert, Seaquest, Space Invaders).
- Average predicted Q-value increases smoothly during training, providing a stable progress metric even when episode rewards are noisy.

## Limitations

- No target network separation (introduced in the later Nature 2015 version) — target values use θ_{i-1} from the previous iteration but not a separate slowly-updated network.
- Uniform replay sampling treats all transitions equally; prioritized experience replay (acknowledged but not implemented) could improve sample efficiency.
- Reward clipping loses magnitude information, potentially hurting performance on games where reward scale matters.
- Evaluated on only 7 games; the later Nature paper extended to 49.
- Struggles on games requiring long-horizon planning and temporal abstraction (Q*bert, Seaquest).
- Single-frame stacking (4 frames) limits the temporal context available to the agent.

## Key takeaways

- Experience replay is the key innovation that makes deep RL stable — by breaking temporal correlations and averaging over past behavior distributions, it transforms the non-stationary RL problem into something closer to the i.i.d. supervised learning regime that deep networks expect.
- A single architecture with no game-specific tuning can learn diverse control policies from raw pixels, establishing that deep RL is a general-purpose method rather than a domain-specific trick (contra the "TD-Gammon was a special case" belief).
- The predicted Q-value is a much more stable training metric than episode reward, a practical insight for monitoring deep RL training.
- This paper launched the deep RL revolution — directly leading to the Nature 2015 DQN paper, and inspiring AlphaGo, A3C, PPO, and the broader integration of deep learning with sequential decision-making.
